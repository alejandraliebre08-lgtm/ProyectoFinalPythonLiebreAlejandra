# Proyecto Final Python (Django) – Tienda Web + Blog (Pages) + Perfiles

Aplicación web desarrollada con **Python + Django** como proyecto final.  
Incluye autenticación (login/logout/signup), perfiles con avatar, módulo de **Pages/Blog** (crear, listar, detalle, editar y borrar), y un módulo tipo **tienda** con clientes, productos y carrito.

---

## 📌 Funcionalidades principales

### ✅ Navegación
- **Home** (inicio)
- **About** (`/about/`) – Información del dueño del sitio
- **Pages/Blog** (`/pages/`) – Listado de páginas con “Leer más”
- Accesos visibles en la **Navbar**: Home, About, Pages, Login, Signup, Profile, Logout

### 👤 Usuarios y perfiles
- Registro de usuario (Signup)
- Inicio/Cierre de sesión (Login / Logout)
- Perfil editable
- **Avatar**: se muestra en la navbar (si no hay imagen, muestra inicial del usuario)

### 📰 Pages / Blog
- Lista de páginas (con mensaje “No hay páginas aún” si no existen)
- Detalle de página al hacer click en **Leer más**

### 🛒 Tienda
- ABM / visualización de **Clientes**
- Visualización de **Productos**
- **Carrito** asociado a usuario
- Total calculado en el carrito (según items y cantidades)

## 🧰 Tecnologías utilizadas
- Python 3.x
- Django 4.x/5.x
- SQLite (por defecto)
- HTML + Bootstrap
